プライバシーポリシー

最終更新日: 2026年10月19日

Flick（以下「本サービス」）は個人が運営するタスク管理アプリです。本サービスが扱う情報とその取り扱いを以下に記載します。

1. 取得する情報

  • Google アカウント情報: Google でログインしたときに、Google のユーザーID、メールアドレス、表示名、プロフィール画像のURLを取得します。要求するスコープは openid・email・profile のみです。
  • タスク: 入力したタスクの本文、ステータス、作成・更新日時。
  • セッション情報: ログイン状態を保つためのセッションIDと有効期限。
  • アクセスログ: リクエストの日時・URL・IPアドレス等が、ホスティング事業者（Cloudflare）の仕組みにより記録されます。

ログインせずに使う場合、タスクはお使いのブラウザ内（localStorage）にのみ保存され、サーバーには送信されません。

2. 利用目的

  • ログインと本人確認
  • タスクを保存し、複数の端末間で同期するため
  • 「✦」ボタンを押したときに、メモをタスクに分解するため
  • 障害の調査と不正利用の防止

広告、行動分析、プロファイリングには使用しません。

3. 保存場所と外部への送信

  • アカウント情報・タスク・セッション情報は Cloudflare D1（Cloudflare, Inc. が提供するデータベース）に保存します。
  • 「✦」ボタンを押した場合に限り、そのメモの本文を Cloudflare Workers AI に送信して処理します。
  • 上記のホスティング・処理の委託先を除き、取得した情報を第三者に提供・販売することはありません。ただし法令に基づく場合を除きます。

4. Google ユーザーデータの取り扱い

本サービスが Google API から受け取った情報の使用および他のアプリへの転送は、Google API Services User Data Policy（Limited Use の要件を含む）に従います。

5. Cookie とブラウザ内の保存

  • ft_sid: ログイン状態を保つ Cookie（HttpOnly、有効期間30日）。サーバーにはこの値のハッシュのみを保存します。
  • ft_oauth_state・ft_oauth_verifier: Google ログイン処理中の安全確認に使う Cookie（有効期間10分）。
  • localStorage: タスクと表示設定をオフラインでも使えるようブラウザ内に保存します。

トラッキング目的の Cookie や外部の解析ツールは使用していません。

6. 保存期間と削除

  • タスクとアカウント情報は、削除を依頼されるまで保存します。
  • セッション情報はログアウト時、または有効期限（30日）で無効になります。
  • アカウントと全データの削除を希望する場合は、下記の連絡先にログインに使ったメールアドレスからご連絡ください。確認後に削除します。
  • Google アカウントのサードパーティ接続の管理から、本サービスへのアクセスをいつでも取り消せます。

7. 安全管理

通信は HTTPS で暗号化しています。Google のアクセストークンはログイン時のプロフィール取得にのみ使い、保存しません。

8. 変更

本ポリシーを変更する場合は、このページで最終更新日とともに告知します。
